# MVSCord YoRHa

Version 1.2.5 · Customized by **MavisWRK**

A classic Discord layout with modern Discord profile customization, styled after the YoRHa interface from NieR: Automata.

## Features

- Beige and olive palette with subtle grid backgrounds.
- Classic sidebar alignment and preserved profile artwork.
- Animated channel, member, and message-author hover effects.
- Integrated SpotifyControls and local activity panel styling.
- Envelope badges for unread DMs, with avatars preserved.
- Standard system cursors and reduced-motion support.

## Install with Vencord

1. Download `MVSCord-YoRHa.theme.css` from this repository.
2. Open Discord Settings → Vencord → Themes and open the themes folder.
3. Copy the CSS file into that folder and enable it under Local Themes.
4. Disable other copies of this theme to avoid conflicting rules.
5. You can use this theme as a online preset, just copy those.
6. `https://raw.githubusercontent.com/MavisWRK/MVSCord-YoRHa/main/MVSCord-YoRHa-Dark.theme.css`.
7. `https://raw.githubusercontent.com/MavisWRK/MVSCord-YoRHa/main/MVSCord-YoRHa.theme-Pink.css`.
8. `https://raw.githubusercontent.com/MavisWRK/MVSCord-YoRHa/main/MVSCord-YoRHa.theme.css`.
9. Go to Online Themes on vencord and paste right there.

To update, replace the file and toggle the theme off and on.

## Compatibility

Developed from the supplied MVSCord layout for desktop Discord with Vencord. Discord updates can change CSS class names and require maintenance. Other themes and plugins may override these styles. The latest activity-panel adjustment still needs visual verification in Discord.

The stylesheet imports `https://milbits.github.io/oldcord/src/components/vars.css`, so that dependency requires an internet connection. YoRHa decorative assets are embedded in the CSS.

## Development

Edit `MVSCord-YoRHa.theme.css`; no build step is needed. Test in Discord after each change, especially DMs, server member lists, profiles, settings, image previews, and voice/Spotify panels.
